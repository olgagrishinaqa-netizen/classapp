# 1. Приложение (папка `app/`, `config.py`)

Приложение — веб-сайт «Классный портал» на Flask. Пользователь входит по номеру телефона и паролю.
Администратор управляет задачами, новостями, расписанием, взносами и расходами, составом класса и
пользователями; остальные (родители, ученики) в основном смотрят.

## Содержание папки

| Путь | Что это |
|---|---|
| `app/__init__.py` | фабрика приложения `create_app()`: собирает Flask-приложение из частей |
| `app/extensions.py` | объект базы данных `db`, общий для всех модулей |
| `app/models.py` | таблицы БД в виде Python-классов (ORM) |
| `app/forms.py` | формы WTForms: описание полей и проверка ввода |
| `app/routes.py` | все страницы и JSON-API (маршруты) |
| `app/audit.py` | журнал входов и действий, метрики Prometheus |
| `app/templates/` | HTML-шаблоны Jinja2 |
| `app/static/` | логотип и иконки |
| `config.py` | настройки для dev и prod |

## `config.py` — настройки

Настройки читаются из переменных окружения (`os.getenv`), чтобы один и тот же образ работал в разных средах.

| Блок | Что делает |
|---|---|
| `class BaseConfig` | общие настройки: `SECRET_KEY` (подпись сессий; по умолчанию `dev-secret`, в проде обязательно задаётся снаружи), `SQLALCHEMY_DATABASE_URI` из `DATABASE_URL` (по умолчанию SQLite-файл), `SESSION_COOKIE_HTTPONLY` (cookie недоступна JavaScript), `SESSION_COOKIE_SAMESITE="Lax"` (защита от CSRF) |
| `ADMIN_NAME/PHONE/PASSWORD` | данные администратора, который создаётся при старте. Телефон по умолчанию — **375290000000** (белорусский формат, как в маске на странице входа) |
| `ADMIN_RESET_PASSWORD_ON_BOOT` | если `true`, пароль админа принудительно сбрасывается на значение из конфигурации при каждом старте. По умолчанию выключено |
| `UPLOAD_FOLDER` | куда сохраняются загруженные файлы (новости, чеки). В Kubernetes это `/uploads`, смонтированный с диска ВМ |
| `MAX_CONTENT_LENGTH` | максимальный размер запроса (10 МБ по умолчанию) |
| `APP_JSON_LOG_PATH` | файл JSON-логов (его читает Promtail) |
| `init_app(app)` | хук проверки при старте; в базовом классе ничего не делает |
| `class DevConfig` | `DEBUG = True`: для локальной разработки допустимы дефолтные секреты и SQLite |
| `class ProdConfig` | `DEBUG = False`. В `init_app` падает с `RuntimeError`, если не заданы `SECRET_KEY` или `DATABASE_URL`. Это «fail fast»: лучше не стартовать, чем работать с `dev-secret` |

## `app/extensions.py`

Две строки: создаётся `db = SQLAlchemy()`. Объект создаётся отдельно от приложения, чтобы модели и
маршруты могли его импортировать без циклических импортов; к приложению он привязывается в `create_app()` через `db.init_app(app)`.

## `app/__init__.py` — фабрика приложения

| Блок | Что делает |
|---|---|
| импорты | Flask, `JsonFormatter` (JSON-логи), SQLAlchemy `inspect`/`text`; `prometheus_flask_exporter` импортируется в `try`, чтобы приложение работало и без него |
| `configure_json_logging(app)` | включает запись логов в файл в формате JSON (поля `timestamp`, `level`, `message`, `path`, `line`). Если нет прав на `/var/log/classapp`, пишет в `instance/`. Не добавляет второй обработчик, если он уже есть |
| `create_app(config_object)` | выбирает класс конфигурации (`FLASK_CONFIG`, по умолчанию `config.DevConfig`), создаёт `Flask`, загружает настройки, включает логи, вызывает `init_app` (проверка секретов) |
| `db.init_app(app)` и `with app.app_context()` | подключает БД. В dev/test создаёт таблицы (`create_all`); в проде схему меняют **только миграции Alembic** |
| bootstrap администратора | если таблица `user` есть: ищет админа по телефону; нет — создаёт; есть — обновляет имя и роль, пароль не трогает (кроме сброса флагом). Если таблицы ещё нет (миграции не прошли), пишет в лог и пропускает |
| Prometheus | если задан `PROMETHEUS_MULTIPROC_DIR` — метрики через gunicorn-воркеры, иначе обычный режим. Даёт эндпоинт `/metrics` |
| `register_blueprint(bp)` | подключает все маршруты из `routes.py` |
| `register_request_audit(app)` | включает общий журнал действий (см. `audit.py`) |
| обработчики ошибок | 500 и любое непойманное исключение: пишут traceback в лог и возвращают JSON `Internal Server Error`; `HTTPException` (404 и т. п.) пропускаются как есть |
| `/healthz` | проба живости: выполняет `SELECT 1` в БД; 200 при успехе, 503 при ошибке. Используется Kubernetes, CI и деплоем |

## `app/models.py` — таблицы

Каждый класс — таблица. Общие приёмы: `db.Column(...)` описывает столбец, `default=local_now` ставит время создания,
`@property` — вычисляемое поле, `db.relationship` — связь между таблицами.

| Класс (таблица) | Назначение | Важные детали |
|---|---|---|
| `local_now()` | текущее время сервера | используется как значение по умолчанию |
| `User` | учётная запись | `phone` уникален и нормализуется (`normalize_phone`: оставляет цифры, `8XXXXXXXXXX` -> `7XXXXXXXXXX`); пароль хранится только хэшем (`set_password` / `check_password`); `is_admin` = роль `admin`; роли: `parent`, `student`, `admin` |
| `ExpenseReport` | сводный отчёт (доход + статьи расходов JSON-ом) | `total_expenses` и `balance` вычисляются |
| `Payment` | взнос от ученика | `student_id` — основная связь; `user_id` устарел (оставлен для старых записей); `payer_name` берёт имя ученика |
| `Expense` | расход бюджета | `receipt_path` — имя файла чека; `receipt_url` = `/uploads/receipts/<имя>` (отдаётся только авторизованным) |
| `Task` | задача класса | `status`: `created`/`in_progress`/`done`; `priority`: `low`/`medium`/`high`; опциональный `deadline` |
| `News` + `NewsImage` | новость и её картинки | статус `draft`/`published`; до 10 картинок; `image_url` — обложка (первая картинка); удаление новости каскадно удаляет картинки |
| `LoginEvent` | журнал входов | `user_id` без внешнего ключа (история остаётся после удаления пользователя); телефон хранится замаскированным (`***1234`) |
| `ScheduleEntry` | урок в недельном расписании | уникально сочетание «день + номер урока» |
| `BellScheduleEntry` | расписание звонков | уникальный номер урока, время начала и конца |
| `GeneralInfo` | общая информация класса | текст и необязательный файл |
| `TaskComment` | комментарий к задаче | таблица есть, интерфейс не использует |
| `Student` | ученик класса | уникально сочетание «фамилия + имя»; `full_name` собирает «Фамилия Имя» |

## `app/forms.py` — формы

Формы описывают поля и правила проверки (`DataRequired` — обязательно, `Length`, `NumberRange`, `Optional`,
`FileAllowed` — допустимые расширения файлов). Flask-WTF добавляет защиту от CSRF (скрытый токен).

| Форма | Для чего |
|---|---|
| `LoginForm` | вход: телефон + пароль |
| `RegisterForm` | регистрация (всегда роль `parent`): имя, телефон, пароль не короче 6, повтор пароля |
| `ExpenseForm`, `PaymentForm` | расход (название, сумма >= 0.01, категория, чек JPG/PNG/WEBP/PDF) и взнос (ученик, сумма) |
| `NewsForm` | заголовок, текст, несколько картинок, статус |
| `TaskForm` | название, описание, дедлайн, приоритет |
| `RoleForm`, `UserRoleForm` | смена своего режима интерфейса; смена роли пользователя админом |
| `UserManagementForm` | создание/редактирование пользователя админом (ФИО, телефон, роль, пароль — необязателен при редактировании) |
| `ScheduleEntryForm`, `BellScheduleEntryForm` | урок (день, номер 1–12, предмет, учитель, кабинет) и звонок (номер, начало, конец). У дня недели нет `DataRequired`: «Понедельник» = 0 считался бы пустым |
| `GeneralInfoForm` | описание + файл (изображение, PDF, DOC(X), XLS(X)) |
| `StudentForm` | фамилия, имя, дата рождения |

## `app/routes.py` — страницы и API

Один `Blueprint("main")`. Файл логически делится на части.

### Вспомогательное (вверху файла)

| Функция | Что делает |
|---|---|
| `current_user()` | достаёт пользователя по `session["user_id"]` |
| `page_user()` | пользователь + «активная роль» (админ может переключиться в режим родителя) |
| `_has_allowed_extension`, `_file_size_exceeds_limit` | проверка расширения и размера файла без чтения его целиком в память |
| `_save_uploaded_file(...)` | безопасное сохранение: `secure_filename`, проверка расширения и размера, уникальное имя `uuid_имя` |
| `_upload_folder()`, `_receipts_folder()` | общий каталог загрузок и подкаталог `receipts/` для чеков |
| `_attach_news_images`, `_remove_news_images`, `_remove_uploaded_file` | прикрепление/удаление картинок новости; файлы, записанные до ошибки, удаляются, чтобы не оставлять «сирот» |
| декораторы `auth_required`, `admin_required` | для JSON-API: 401 без входа, 403 не-админу |
| `login_required_page`, `admin_required_page` | для HTML-страниц: редирект на `/login`, либо сообщение и редирект на дашборд |
| `user_json`, `task_json`, `news_json` | превращают объекты БД в словари для JSON |

### HTML-страницы

| Маршрут | Доступ | Что происходит |
|---|---|---|
| `/` | все | перенаправляет на дашборд или на вход |
| `/login` (GET/POST) | все | проверка телефона и пароля; при успехе в сессию пишутся `user_id` и `active_role`, обновляется `last_login`, пишется событие аудита; при неудаче — сообщение об ошибке (одинаковое для «нет такого номера» и «неверный пароль») |
| `/register` | все | создание аккаунта родителя; дубль номера отклоняется |
| `/logout` (POST) | вошедшие | очищает сессию |
| `/dashboard` | вошедшие | число активных задач, последняя опубликованная новость, расходы за месяц |
| `/news`, `/news/<id>/edit`, `/news/<id>/delete` | просмотр — все (черновики видит только админ); изменения — админ | CRUD новостей с картинками |
| `/schedule` (+ `/<id>/edit`, `/<id>/delete`) | просмотр — все; изменения — админ | расписание уроков; ошибка уникальности (`IntegrityError`) превращается в понятное сообщение |
| `/bell-schedule` (+ edit, delete) | то же | расписание звонков; конец должен быть позже начала |
| `/info` (+ edit, delete) | то же | общая информация с файлом |
| `/admin/login-log` | админ | журнал входов: фильтры, пагинация по 30, статистика за 24 часа |
| `/users`, `/users/edit/<id>`, `/users/delete/<id>`, `/users/<id>/role` | админ | управление пользователями. Защиты: нельзя удалить себя, нельзя удалить/разжаловать последнего админа, нельзя удалить пользователя с историей взносов; номер должен быть формата +375 (XX) XXX-XX-XX |
| `/admin/students` (+ edit, delete) | админ | состав класса с поиском по словам |
| `/profile`, `/change_role` | вошедшие | переключение режима интерфейса админ/родитель |
| `/tasks`, `/tasks/<id>/complete` | просмотр — все, изменения — админ | список задач (активные сортируются по приоритету и дедлайну), переключение «сделано» |
| `/expenses`, `/expenses/edit/<id>`, `/payments/edit/<id>` | просмотр — все, изменения — админ | взносы и расходы; чеки сохраняются в `UPLOAD_FOLDER/receipts`; баланс = сумма взносов минус сумма расходов |

### JSON-API (`/api/...`)

| Маршрут | Доступ | Что делает |
|---|---|---|
| `POST /api/login`, `/api/logout`, `GET /api/me`, `POST /api/role` | — | вход/выход и сведения о текущем пользователе |
| `GET/POST /api/users`, `PUT /api/users/<id>` | админ | список, создание, изменение пользователей |
| `GET/POST /api/news`, `PATCH /api/news/<id>` | чтение — вошедшие, запись — админ | новости с картинками |
| `GET/POST /api/tasks`, `PATCH /api/tasks/<id>` | чтение — вошедшие, запись — админ | задачи и смена статуса |
| `GET/POST /api/reports` | админ | сводные отчёты с чеком |
| `GET /uploads/<путь>` | **только вошедшие** | отдача загруженных файлов, включая `receipts/...`; без входа — 401 |

## `app/audit.py` — аудит и метрики

| Элемент | Что делает |
|---|---|
| `LOGIN_ATTEMPTS`, `USER_ACTIONS`, `REGISTRATIONS` | счётчики Prometheus: попытки входа (успех/неудача, канал), изменяющие действия по эндпоинтам, регистрации |
| `client_ip()` | IP клиента из заголовка `X-Real-IP`, который nginx перезаписывает значением `$remote_addr` (подделать снаружи нельзя) |
| `mask_phone()` | `375290000000` -> `***0000`: полный номер в логи и журнал не попадает |
| `_store_event()` | сохраняет событие входа в таблицу `login_event`; сбой записи только логируется и не ломает вход |
| `audit(event, **fields)` | пишет событие в JSON-лог (читает Promtail -> Loki) и, для событий входа, в БД |
| `audit_login(...)` | обёртка для результата входа (+ счётчик Prometheus) |
| `register_request_audit(app)` | хук `after_request`: каждое изменяющее действие (POST/PUT/PATCH/DELETE) пишется в лог с пользователем, ролью, эндпоинтом, статусом |
| `describe_device()` | по User-Agent собирает «Android · Chrome» для журнала |

## `app/templates/` — шаблоны

Jinja2-шаблоны наследуют `base.html` (шапка, меню, тема светлая/тёмная, стили Tailwind через CDN) и
подставляют свои блоки. Названия соответствуют страницам: `login`, `register`, `dashboard`, `tasks`, `news`
(+ `news_edit`), `schedule`, `bell_schedule`, `general_info` (+ edit), `expenses` (+ `expense_edit`,
`payment_edit`), `users`, `admin_students`, `login_log`, `profile`, `_carousel` (карусель картинок новости,
подключается в `news`). Внутри шаблонов: `{{ ... }}` — вывод значения (HTML экранируется автоматически),
`{% ... %}` — управляющие конструкции, `url_for(...)` — адрес маршрута, `form.поле` — поле формы.
`app/static/` содержит логотип и иконки.
